One Wi-Fi network name of at most 32 characters that lands a joke and implies a whole story: "My Ex Changed the Password" — a breakup, a shared home, a petty revenge, and a lockout, told in six words a passer-by reads in their phone's network list.

## Run it

```sh
python3 main.py
```

It validates the name (one line, 1–32 characters) and writes it to `/output/entry.txt`.
